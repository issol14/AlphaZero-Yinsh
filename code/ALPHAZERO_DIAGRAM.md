## 📊 주요 컴포넌트 설명

### Environment (YinshEnv)
- **육각형 보드**: 11x11 배열로 구현, valid_points로 유효한 위치 제한
- **게임 상태**: 링 배치 → 메인 게임 → 종료
- **액션**: 링 배치, 링 이동, 마커 뒤집기, 라인 제거

### Neural Network (YinshModel)
- **입력**: 11x11x3 (보드 상태, 플레이어, 게임 단계)
- **출력**: Policy (액션 확률), Value (승률 예측)
- **아키텍처**: ResNet 기반 CNN

### MCTS (YinshMCTS)
- **트리 탐색**: UCB1 공식으로 노드 선택
- **신경망 평가**: 리프 노드에서 정책/가치 예측
- **백프로파게이션**: 승률 정보를 루트까지 전파

### Agent (YinshAgent)
- **액션 선택**: MCTS + 신경망 조합
- **탐험**: Temperature로 확률적 선택
- **학습**: Self-play 데이터로 훈련

## 🎮 게임 규칙 구현

### 링 배치 단계
- 각 플레이어가 5개의 링을 유효한 위치에 배치
- 마커가 있는 곳에는 링을 둘 수 없음
- 모든 링 배치 완료 시 메인 게임으로 전환

### 메인 게임 단계
1. **링 이동**: 직선 경로로 링 이동
   - 링이 가로막으면 그 부분까지만 이동 가능
   - 마커가 있으면 그 다음 칸까지 이동 가능
   - 마커가 있는 곳에 링을 둘 수 없음
   - **링 이동 시 자기 자리에 마커 생성**
2. **마커 뒤집기**: 경로상의 마커 색상 변경 (있는 경우)
3. **라인 제거**: 5개 연속 마커 시 제거
4. **링 제거**: 라인 제거 시 링도 함께 제거

### 승리 조건
- 3개의 링을 제거한 플레이어가 승리
